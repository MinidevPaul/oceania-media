# Oceania media

Screenshots, GIFs and trade-screen captures for the Oceania Minecraft mod page.

Screenshots were taken in Minecraft 1.21.1 with the Patrix 64x resource pack and a shader pack; the crafting GIFs and trade screens are plain vanilla UI.

- `images/` full-width screenshots (WebP, 1920 wide) and `banner_16x9`
- `gifs/` crafting animations as GIF and animated WebP
