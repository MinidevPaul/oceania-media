# Oceania media

Screenshots, GIFs and trade-screen captures for the Oceania Minecraft mod page.

Screenshots were taken with the Packtrix resource pack and AstraLex shaders; the crafting GIFs and trade screens are plain vanilla UI.

- `images/` full-width screenshots (WebP, 1920 wide) and `banner_16x9`
- `gifs/` crafting animations as GIF and animated WebP
- `clips/` short clips as mp4, animated WebP and GIF, all under 10 MB

A `.gif` or `.webp` raw link embeds and plays when pasted into Discord. A `.mp4` raw link does not, because GitHub serves it as `application/octet-stream`; upload the file directly instead.
